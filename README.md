# Dashboard de gestion de parc — version web

Ce dépôt contient **uniquement le programme** (scripts compactés, feuille de style, polices, icônes).

**Aucune donnée n'est ici.** Les données (véhicules, chauffeurs, affectations, amendes, sinistres, etc.)
et les paramètres propres à l'entreprise restent dans le dossier `Data` du partage réseau. À la première
ouverture, le navigateur (Microsoft Edge) demande l'accès à ce dossier ; sans cet accès, le site n'affiche rien.

Ce contenu est publié automatiquement après un contrôle qui refuse toute donnée sensible
(noms, téléphones, immatriculations, paramètres de l'entreprise).
